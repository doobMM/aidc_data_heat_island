## §16. 에너지바우처 발급 — 냉방 지원은 어디에 닿는가 `[사실]` `[🔖 2026-07-20]`

**자료**: 한국에너지공단 정보공개청구 회신(접수번호 17002726), 2020~2025 연도 × 시군구 × 세대원특성별 **발급 가구수**.

### ⚠ 청구했으나 받지 못한 것 — 이게 분석 범위를 결정한다

| 청구 항목 | 결과 |
|---|---|
| 발급 가구수 (연도·시군구) | ✅ 공개 |
| 세대원 특성별 발급 가구수 | ✅ 공개 |
| **하/동절기 사용 가구수·사용액** | ❌ **정보부존재** |

회신 사유: *"에너지바우처 신청이 연중 상시(매년 6월~12월) 진행됨에 따라, 하절기 사용기간(7~9월)이 경과한 후 신청하신 수급자의 실적 집계가 불가"* → 절기별 사용 실적은 **기관이 보유·관리하지 않는 정보**(정보공개법 제11조제5항제1호).

**따라서 '발급받고도 못 쓴 가구'는 이 자료로 셀 수 없다.** 원래 하려던 *"하계 바우처 사용률이 낮다"* 는 검증은 **불가능**하다. 게다가 에너지바우처는 **신청주의**라, 자격이 있어도 신청하지 못한 가구는 발급에도 잡히지 않는다.

> ⇒ **발급 가구수는 '제도가 닿은 최대치'(도달의 상한)다. 실제 도달은 이보다 작다.** 이 노트북의 모든 §16 수치는 그렇게 읽어야 한다.

### ⚠ 세대원 특성은 우선순위 배타 집계다
자료 머리말 명시: *"복수의 세대원 특성을 가질 시 **다자녀 → 소년소녀 → 한부모 → 질환자 → 임산부 → 영유아 → 장애인 → 노인** 우선순위로 집계"*. 실제로 특성 합 ÷ 가구수 = **정확히 1.000**이다(한 가구가 1회만 계상).
**노인이 최하위 우선순위**이므로 '노인이면서 장애인'인 가구는 장애인으로 잡힌다 → **노인 수치는 구조적 과소**다. 폭염 취약 분석에서 반드시 함께 읽어야 한다.
(다자녀는 2025년 신규 추가라 2024년까지 0이다.)

```python
# ── §16-a. 로드 + 행정구역 정규화 ──
import python_calamine as pc
CH=['다자녀','소년소녀가정','한부모가정','질환자','임산부','영유아','장애인','노인']
_raw=pc.CalamineWorkbook.from_path(
 '정보공개청구에 대한 답변_연도·시군구·세대원특성별 에너지바우처 발급가구수(20-25년도).xlsx'
 ).get_sheet_by_name('Sheet1').to_python()
print('머리말:', ' | '.join(str(c) for c in _raw[0] if str(c).strip()))
VB=pd.DataFrame(_raw[2:],columns=[str(c).strip() for c in _raw[1]])
for c in ['가구수']+CH: VB[c]=pd.to_numeric(VB[c],errors='coerce').fillna(0)
VB['연도']=pd.to_numeric(VB['사업연도'],errors='coerce').astype(int)
VB['시군구']=VB['시군구'].astype(str).str.strip()

# 정합성: 특성 합 = 가구수 인가 (우선순위 배타 집계 확인)
_chk=(VB[CH].sum(axis=1)/VB['가구수'].replace(0,np.nan))
print(f"특성합/가구수: 중앙값 {_chk.median():.3f} · 범위 {_chk.min():.2f}~{_chk.max():.2f} → 1.000이면 배타 집계 확인")

# 행정구역 개편·표기 4건 정규화 (모두 자료 제공기관 표기 문제)
_GJ={'동구','서구','남구','북구','광산구'}
_m=VB.시도=='전남광주통합특별시'          # 2025년만 전남·광주를 합쳐 표기. 광주 자치구 5개는 이름으로 구분 가능
VB.loc[_m,'시도']=np.where(VB.loc[_m,'시군구'].isin(_GJ),'광주','전남')
VB['시군구']=VB['시군구'].str.replace(r'^창원시 .+$','창원시',regex=True)   # 창원 구 단위 소량 누출(18~35가구) → 시로 합산
VB.loc[VB.시도=='세종','시군구']='세종특별자치시'                            # '세종'·빈칸 혼재
_SIDO={'서울':'서울특별시','부산':'부산광역시','대구':'대구광역시','인천':'인천광역시','광주':'광주광역시',
       '대전':'대전광역시','울산':'울산광역시','세종':'세종특별자치시','경기':'경기도','강원':'강원특별자치도',
       '충북':'충청북도','충남':'충청남도','전북':'전북특별자치도','전남':'전라남도','경북':'경상북도',
       '경남':'경상남도','제주':'제주특별자치도'}
VB['key']=VB.시도.map(_SIDO)+' '+VB.시군구
VB=VB.groupby(['key','연도'],as_index=False)[['가구수']+CH].sum()
VB.loc[VB.key=='대구광역시 군위군','key']='경상북도 군위군'   # 바우처는 대구 편입을 전 기간 소급, 우리 패널은 경북

_P=pd.read_csv('DERIVED_0718_시군구연도_패널_온열전력.csv',encoding='utf-8-sig')
VM=_P.merge(VB,on=['key','연도'],how='left')
print(f"\n패널 접합 {VM.가구수.notna().mean()*100:.1f}% (미매칭 {int(VM.가구수.isna().sum())}행)")

# 인천 2025 개편 — 우리 핵심 부지가 걸린다
_IC={'인천광역시 제물포구','인천광역시 영종구','인천광역시 검단구','인천광역시 서해구'}
print(f"⚠ 인천 2025 개편: 동·중·서구 → 제물포·영종·검단·서해구 (신설구 2025 발급 {int(VB[(VB.연도==2025)&(VB.key.isin(_IC))].가구수.sum()):,}가구)")
print("   §13의 '인천 동구 현대제철·동국제강' 부지는 행정상 제물포구가 된다. 좌표는 불변.")
print("   → 시군구 단위 비교는 동구가 살아있는 2020~2024로 한정한다.")
VM=VM[VM.연도<=2024].copy()
VM['발급률_인구천명']=VM.가구수/VM.인구*1000
VM['노인비중']=VM.노인/VM.가구수*100
VM.to_csv('DERIVED_0720_시군구연도_에너지바우처_발급.csv',index=False,encoding='utf-8-sig')
print(f"저장: DERIVED_0720_시군구연도_에너지바우처_발급.csv ({len(VM)}행)")
```

```python
# ── §16-d. 발급률은 무엇의 신호인가 — '잘 닿는다' vs '취약한 사람이 많다' ──
def _pc(d,a,b,c='인구'):
    x,y,z=d[a].values,d[b].values,d[c].values
    rc=lambda u,v:np.corrcoef(u,v)[0,1]
    r=(rc(x,y)-rc(x,z)*rc(y,z))/np.sqrt((1-rc(x,z)**2)*(1-rc(y,z)**2))
    n=len(d); p=2*stats.t.sf(abs(r*np.sqrt((n-3)/(1-r**2))),n-3)
    return r,('***' if p<.001 else '**' if p<.01 else '*' if p<.05 else 'n.s.')
print('편상관 (인구 통제, 2024, n=%d)'%len(_q))
for b,lbl in [('여름온열률10만','여름 온열질환률'),('주택용여름','주택용 여름전력'),('산업용여름','산업용 여름전력')]:
    if b in _q.columns:
        r,s=_pc(_q,'발급률_인구천명',b); print(f'  발급률 ↔ {lbl:14}: r={r:+.3f} {s}')

print('\n발급률 상·하위 8 (2024)')
_c=['key','인구','발급률_인구천명','노인비중','여름온열률10만']
_s=_q.sort_values('발급률_인구천명',ascending=False)
print('  ▲ 상위'); print(_s.head(8)[_c].to_string(index=False,float_format=lambda x:f'{x:,.1f}'))
print('  ▼ 하위'); print(_s.tail(8)[_c].to_string(index=False,float_format=lambda x:f'{x:,.1f}'))
```

### §16 결과·해석 규약 `[🔖 2026-07-20]`

#### 측정된 것 `[사실]`
- **제도는 확대됐다** — 발급 가구가 2020년 66만 → 2024년 125만, 인구천명당 12.8 → 24.7로 **1.9배**.
- **받는 사람의 절반이 어르신** — 2024년 세대원 특성 구성은 노인 46.4% · 장애인 31.1% · 한부모 11.3% · 질환자 9.0%. (노인은 배타 집계로 과소이므로 실제 고령 가구 비중은 더 높다.)
- **★ 발급 분포는 폭염 피해 분포와 무관하다** — 발급률 ↔ 여름 온열질환률 편상관 **r = −0.023 (n.s.)**.
- **발급률이 높은 곳일수록 여름 주택 전력을 덜 쓴다** — r = −0.200 (**).

#### 발급률은 '도달'이 아니라 '취약도'의 신호다 `[해석]`
발급률 상위는 부산 영도구(72.8)·중구(68.9)·동구(64.1), 김제, 영덕, 대구 남구. 하위는 옹진군(3.5)·과천(7.8)·서초(8.5)·용인(9.2)·화성(9.8). **명백한 소득 지형**이다.
에너지바우처는 기초생활수급 등 **소득·자격 기준**으로 배분되므로, 발급률이 높다는 것은 제도가 잘 닿았다기보다 **그 지역에 자격을 갖춘 가구가 많다**는 뜻이다. 발급률만으로 도달률을 말할 수 없다 — 분모(자격자 수)를 이 자료로는 알 수 없기 때문이다.

#### 도달 격차의 구조 `[해석]`
> **냉방 지원은 '가난한 곳'을 향하고, 폭염 피해는 그와 다른 곳에서 난다.** 두 분포가 서로 무관하다(r≈0)는 것이 이 자료의 핵심이다.

이는 제도의 실패라기보다 **설계상 그렇게 되어 있는 것**이다. 에너지바우처는 소득 지원이지 폭염 대책이 아니다. 다만 폭염 대책의 자리를 이것이 대신하고 있다면, 그 격차는 실재한다.

그리고 발급률↔주택용 여름전력의 **음(−)의 관계**는, 지원을 받는 가구가 많은 지역일수록 여름 냉방 소비가 적다는 뜻이다. 바우처가 실제 냉방 사용으로 이어지는지는 **사용 자료가 없어 확인할 수 없다**(정보부존재).

#### AIDC 후보 부지에서 `[사실]`
인천 동구는 발급률 **37.4**(전국 중앙 29.3의 1.27배, 227개 중 53위), 바우처 가구 중 노인 **48.2%**, 여름 온열질환률 **10.3**/10만(전국 중앙 7.9). 즉 §13에서 확인한 *3km 21만 명·65세 이상 22.8%* 에 더해 **냉방비 부담이 큰 가구가 밀집한 지역**이다.
반대로 구미(16.4)·당진(17.5)·울산남구(18.7)·광양(18.4)은 전국 중앙의 0.56~0.64배다.

#### ⛔ 말하지 않는 것 `[해석 금지]`
1. **"하계 바우처 사용률이 낮다"** — 사용 자료가 **정보부존재**다. 이 자료로 검증도 반증도 할 수 없다.
2. **"발급률이 높으니 그 지역은 냉방 지원이 잘 닿는다"** — 발급률은 자격자 밀도에 지배된다. 도달률(발급÷자격자)은 계산 불가.
3. **"바우처가 온열질환을 줄이지 못했다"** — r≈0은 *분포가 정렬돼 있지 않다*는 뜻이지 *효과가 없다*는 뜻이 아니다. 효과 추정에는 사용 자료와 시계열 설계가 필요하다.
